### 🎯 Objective

To design and simulate a real-time IoT Based Temperature Monitoring System using Arduino UNO and TMP36 sensor and display the temperature on LCD and Serial Monitor.

---

### 🔧 Components Used

- Arduino UNO R3
- TMP36 Temperature Sensor
- 16x2 LCD Display
- Potentiometer
- Breadboard
- Jumper Wires

---
### 💻 Working Principle

1. Sensor senses temperature and gives output in volts
2. voltage is converted to temperature: `(voltage - 0.5) * 100`
3. Displayed on LCD and Serial Monitor

### ✅ Test Results

The circuit was simulated in Tinkercad and tested successfully.

- Temperature value is displayed correctly on LCD.
- Serial Monitor shows accurate temperature readings.
- System works without any errors.
