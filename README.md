Project:IOT based temperature monitoring sensor 
Domain:Internet of things(IOT)
Tinkercad link: https://www.tinkercad.com/things/2pY7X7CADNE-upskill-campus-project-iot-temperature-monitoring-system?sharecode=HQX2LhSzm9k0KO_dumTvbttkfUq5r0CEkPL6GZAqwHY
Objective:To design and simulate an iot based temperature monitoring system using Arduino UNO,TMP36 sensor and 16x2 LCD to display real time temperature in celsius.
Components Used:
              *Arduino UNO R3
              *TMP36 Analog temperature sensor
              *16x2 LCD Display
              *Potentiometer
              *Breadboard and Jumper wires
